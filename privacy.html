multi-account プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-10-28

1. 対象 / Scope

multi-account は開発者本人だけが使う個人用ツールです。本人以外のユーザーはいません。

multi-account is a personal tool used only by its developer. It has no other users.

2. 扱うデータ / Data accessed

本人が許可した Google アカウントについて、Gmail のメール、Google ドライブのファイル、Google カレンダーの予定を、Google の API を通じて読み取ります。本人の指示があったときだけ、メールの下書き・送信、ファイルのアップロード、予定の作成を行います。

For the Google accounts the developer has authorized, the app reads Gmail messages, Google Drive files and Google Calendar events through Google APIs. It drafts or sends email, uploads files or creates events only when the developer explicitly asks.

3. データの使い方 / How data is used

  • データは本人のコンピューターの中で処理し、本人が自分の情報を確認・整理するためだけに使います。/ Data is processed on the developer's own computer, solely so the developer can review and organize their own information.
  • 本人の指示で、メールの内容の一部を AI モデルの提供者（Anthropic）に送り、要約やタスクの抽出をさせることがあります。/ At the developer's request, parts of email content may be sent to an AI model provider (Anthropic) to summarize them or extract tasks.
  • データを販売・広告に使ったり、上記以外の第三者に渡したりしません。/ Data is never sold, used for advertising, or shared with any other third party.
  • 開発者が運営するサーバーはなく、データをサーバーに保存しません。/ There is no server operated by the developer, and no data is stored on any such server.

Google API から受け取った情報の利用と他のアプリへの移転は、Limited Use の要件を含む Google API Services User Data Policy に従います。

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 保存と削除 / Storage and deletion

認証情報は本人のコンピューターのキーチェーンにだけ保存します。アクセスは、Google アカウントの「サードパーティによるアクセス」からいつでも取り消せます。

Credentials are stored only in the keychain of the developer's computer. Access can be revoked at any time from the Google Account's third-party access settings.
